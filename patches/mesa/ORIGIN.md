# Origin of the Mesa patches

These patches are copied unchanged from [PS5LM](https://github.com/cobanov/PS5LM)
at commit `6323ecb` (v0.9.0, GPL-3.0). PS5LM took them from
[PS5CEMU-HAR](https://github.com/premohq/PS5CEMU-HAR), which carries the RADV changes
for the PS5 GPU. See `README.md` in this directory for what each patch does and the
Mesa revision they apply to.
