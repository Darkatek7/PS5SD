Installed models

LoRAs

A LoRA adds a style, a character or a look to a model. It works only with models of the family it was made for (SD 1.5, SDXL, FLUX…). Pick them on the Create tab, under Settings. DMD2 (anime) and SDXL-Lightning (photos) make SDXL models fast: CFG 1, 4 to 8 steps, sampler LCM for DMD2 and Euler for Lightning. CausVid does the same for Wan 2.1 1.3B videos: CFG 1, 4 steps.

Upscalers

An upscaler (ESRGAN) makes an image larger and sharper: with the Upscale button, or in the hires fix on the Create tab. More of them: a link as Upscaler under Add by link, a .pth file as Upscaler under Upload, or Civitai's upscalers.

Downloads

Get more models

This version of the PS5SD app cannot download models. Copy model files into /data/PS5SD/models on the console, then press Refresh.

Catalog

Add by link

A link to a file on huggingface.co, or a Civitai model version (a link that ends in modelVersionId=...). The file goes into the models folder on the console, or the loras folder for a LoRA; a Civitai LoRA goes there by itself.

Upload from this computer

Any model file on this computer: your own merge or training, or one from another site. It keeps its file name. A model in several files also needs a preset; docs/MODELS.md shows how. Keep this page open until the upload is done.

Search Hugging Face

Saved presets

A preset is a model with your settings: size, steps, CFG, sampler and LoRAs. Use switches to it; when it is the model that is loaded already, at once. Delete removes only the preset, never the model.

Save the current settings

Change the settings on the Create tab first. The model's own options (VAE, tiling and so on) come along.
